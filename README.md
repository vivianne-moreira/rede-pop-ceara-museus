## Rede Pop Ceará — Mapa de Museus

Mapeamento aberto e interativo dos equipamentos culturais e museus do Estado do Ceará, desenvolvido em parceria com o **Instituto Federal do Ceará (IFCE)** através da **Rede Pop Ciência**.

O projeto visa democratizar o acesso à cultura e apoiar os **Objetivos de Desenvolvimento Sustentável (ODS)** da ONU, com foco no **ODS 10** (Redução das Desigualdades) e **ODS 11** (Cidades Sustentáveis e Comunidades).

---

## Principais Funcionalidades

- **Listagem e Grade de Museus:** Visualização limpa e organizada de todos os equipamentos cadastrados.
- **Mapa Interativo:** Localização geográfica integrada para visualização espacial dos museus cearenses.
- **Filtros Avançados:** 
  - Busca por nome ou cidade/município.
  - Filtro por categorias temáticas (História, Artes, Ciências, Ecomuseus, etc.).
  - Filtro rápido de acessibilidade confirmada.
- **Painel de Gestão Protegido:** Sistema de senha de sessão para que apenas a equipe autorizada possa cadastrar novos museus, editar informações ou marcar registros como revisados.
- **Banco de Dados em Nuvem:** Dados persistidos em tempo real utilizando Supabase (PostgreSQL), permitindo colaboração simultânea de múltiplos usuários.

---

## Tecnologias Utilizadas

Este projeto foi construído com ferramentas modernas de ecossistema front-end:

- **[Vue.js 3](https://vuejs.org/)** (Composition API) — Framework progressivo para construção da interface.
- **[Vite](https://vitejs.dev/)** — Ferramenta de build rápida e moderna.
- **[Tailwind CSS](https://tailwindcss.com/)** — Framework utilitário de estilização CSS.
- **[Supabase](https://supabase.com/)** — Backend-as-a-Service (BaaS) utilizando PostgreSQL para gerenciamento do banco de dados em tempo real.
- **[Leaflet](https://leafletjs.com/)** — Biblioteca de mapas interativos.
